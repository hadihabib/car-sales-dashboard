# تطبيق إدارة مبيعات قطع السيارات

مشروع Flutter جديد بالكامل بدون Login.

## أول تشغيل

التطبيق يطلب فقط:

- Supabase Project URL
- Supabase Publishable Key

ويحفظهما على الهاتف. بعد ذلك يفتح مباشرة كل مرة.

لا يوجد أي مفتاح داخل GitHub.

استخدم فقط:

`sb_publishable_...`

ولا تستخدم:

`sb_secret_...`

## 1. إعداد Supabase

افتح:

Supabase > SQL Editor > New query

وشغّل:

`supabase_schema_no_auth.sql`

إذا الجداول موجودة، الملف لا يمسحها لأنه يستخدم:
`create table if not exists`

لكنه يعطل RLS ويعطي Publishable/anon صلاحية القراءة والكتابة
لأنك طلبت التطبيق بدون Login أو حماية.

## 2. رفع GitHub

ارفع كل ملفات المشروع إلى Repository.

لا تضف أي Secret.

## 3. بناء APK من GitHub

بعد رفع المشروع:

1. افتح تبويب Actions
2. اختر Build Android APK
3. اضغط Run workflow
4. بعد نجاح البناء افتح آخر Run
5. انزل إلى Artifacts
6. نزّل:
   `car-sales-manager-apk`
7. فك الضغط
8. ثبت `app-release.apk`

## 4. أول تشغيل على الهاتف

من Supabase > Project Settings > API Keys

خذ:

- Project URL
- Publishable Key

وحطهم داخل التطبيق.

اضغط اختبار الاتصال ثم حفظ.

## تغيير المفاتيح لاحقاً

من:
الإعدادات > تغيير الاتصال

ويمكنك أيضاً مسح الإعدادات من الجهاز وإدخالها من جديد.
